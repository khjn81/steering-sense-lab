# 품질과 검증 범위

## 평가 방법

원본의 단위 검사 35개는 통과했습니다. 새로 고정한 브라우저 12개 중 5개가 통과했고, 구현 담당 에이전트의 루브릭 판단은 39/100이었습니다. [고정 기준](../quality/rubric.json)은 20항목, 각 0~5점입니다. 독립적인 사람 평가나 학습 효과 점수가 아닙니다.

기준선·검사 구성과 원래 브라우저 판정 파일의 해시를 고정했습니다. 개선마다 관찰·가설·변경·명령·결과·채택 여부를 기록했습니다. 새 경계 검사는 수정 전 실패를 확인했고, 최종 브라우저 여정은 별도로 실행합니다. 설치와 검사 도구 준비는 개선 횟수에 넣지 않습니다.

20회 개선 후 루브릭 판단은 76/100입니다. 실행 결과와 각 회차는 [실험 요약](../quality/experiments.json)에 반영합니다. 로컬 최종 검증 결과와 원격 CI 결과는 아래 실행 기록을 기준으로 갱신합니다.

## 확인한 흐름

- 시나리오 선택, 조향·전후진·정지, 되감기·재생, 예측 퀴즈
- 도움말 입력 격리, 기본 폼 키보드 동작, Escape 정지
- 페이지 이탈·숨김, 실제 WebGL 손실과 2D 복구
- 합성 영상의 보정·추적 손실·미래/역순 시각·종료·취소·늦은 콜백·작업 정지
- 두 개의 브라우저 터치 포인터로 동시 조향·후진
- 실제 로컬 WASM·모델의 빈 영상 추론, 서버 정책·MIME·공개 경계
- 기록 상한, 점선 버퍼 재사용, 2D 정지 상태의 그리기 중단
- 원본 패키지·모델 바이트와 무결성, 별도 복사본 설치와 회귀 검사

모바일은 에뮬레이션입니다. 합성 카메라 검사는 실제 카메라를 요청하지 않습니다. 빈 영상 추론이 성공해도 실제 손 인식 정확도를 검증한 것은 아닙니다. 실기기 발열·배터리·메모리 양이나 실제 주차 안전은 측정하지 않았습니다.

## 보존한 실패와 재검증

- 3회차의 선택식이 아직 수정하지 않은 페이지 이탈 사례도 골랐습니다. 해당 실패를 보존하고 정지와 페이지 이탈을 분리해 재검증했습니다.
- 15회차에서 기록 상한 검사는 통과했으나, 경계 상태를 넣은 테스트가 화면 상태를 갱신하지 않아 재생 검사가 실패했습니다. 같은 보완한 테스트로 원본의 4,001개 초과와 후보의 상한·순서·재생을 다시 확인했습니다.
- 동시 터치 검사는 종료한 터치를 다시 취소하는 정리 코드 오류가 있었습니다. 판정 조건을 유지하고 정리 순서만 바로잡아 두 화면 크기에서 재실행했습니다.
- 서버 정책 통합 검사는 기존 보정 안내가 한 프레임 뒤 덮이는 문제를 드러냈습니다. 불안정한 자세 상태를 유지하도록 고쳤으며 대기 시간이나 판정 조건을 완화하지 않았습니다.

## 공개 범위

공개용 orphan 브랜치는 원본 해커톤 저장소와 배포 설정을 보존합니다. 애플리케이션·검사·의존성·출처·요약만 포함하며, 개인 자료·비공개 사이트 설정·연구 문서·로컬 절대 경로가 든 원시 로그와 브라우저 추적은 제외합니다.

- 최종 실시간 주차 세 장면은 통과했지만 WebKit에서 도움말 종료 뒤 포커스 복원이 실패했습니다. 닫기 이벤트에서 호출 버튼으로 포커스를 돌리고 세 브라우저 입력 환경을 다시 확인했습니다.
